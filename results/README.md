# Results

This directory receives generated analysis outputs. For MATLAB sample `X` (`X = 1, 2, 3, 4`), the principal files are `quiescentcells_sampleX.dat`, `distances_sampleX.dat`, `RootMeanSquaredError_sampleX.dat`, `final_particles_sampleX.dat`, `BestParsSampleX.dat`, and `MinQuiescSampleX.dat`.

The Python figure-generation programs create `Extended_Data_Fig_5a.pdf`, `Extended_Data_Fig_5a.png`, `gS_estimates.csv`, `Extended_Data_Fig_5b.pdf`, `Extended_Data_Fig_5b.png`, and `gR_estimates.csv`.

Reference Python outputs generated from the deposited workbook are included so reviewers can compare their results. They can be regenerated by running the programs. The MATLAB output files are not included because each 25-population run requires approximately 45–60 minutes; their names and correspondence with the manuscript are described in the main README.
